title: "Marketing Tools: Reference Emails"
description: How to use the 4Site reference emails as a starting point for building an email broadcast
---

Reference emails are pre-built emails - with a pre-configured template and blocks - that can act as a starting point for your work in building out a broadcast.

In our standout build, there is one reference email:

- 4Site Reference Email

You can find the Reference Emails inside the "Ω. 4Site Reference Emails" folder of the "Broadcasts" section in Marketing Tools.

To use a Reference Email, you can copy it by clicking on the copy button, then move it to your desired folder:

![Copying a reference email using the copy button](/images/marketing-tools/reference-email-copy.png)

Feel free to make your own Reference Emails for any other use cases you have.
